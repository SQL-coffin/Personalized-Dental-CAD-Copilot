# 02 · 数据规范

版本：v0.5 草案

v0.5 变更：
- 支持标准病例设计（[03](03-experiment-protocol.md) 第 4.1 节）：Case 与 Session 增加标准病例、提供者、会话顺序、重复会话等字段（第 1.1 节）。
- GD 增加解剖分区 `sector`，用于跨病例比较个人偏移（第 4 节）。
- 数据集准入增加 H0 分析（第 12.3 节）。

v0.4 变更：
- 新增「动作—中间版本—区域—GD」的数据链（第 6 节），让被覆盖和撤销的修改不会被最终净位移抹去。
- 新增采集粒度等级（第 6.5 节），决定每个会话可以支持哪些分析。
- 局部坐标系（第 10 节）：法向分量不再假定接近 0；表面贴合改为单独检查；增加参数敏感性要求。
- 结果记录（第 12 节）：区分四类质量证据；增加数据集准入规则。

v0.3 变更：拆分 Geometry Delta / Correction Episode / Validated Improvement；明确学习目标；曲线对应分为 MATCHED / AMBIGUOUS / UNMATCHED；用多字段结果记录取代单一标签等级。

数据结构先于模型设计。

## 1. 数据层级

| 层级 | 内容 |
|---|---|
| Case · 病例 | 修复体类别、牙位、匿名化病例 ID、**匿名化患者 ID**、扫描和网格版本 |
| Session · 建模会话 | 软件状态、时间、相机视角、操作工具、采集粒度等级（第 6.5 节） |
| Episode · 修正任务 | 一次连续的修正任务（定义见第 5 节） |
| Evidence · 事件与证据 | 动作日志、几何版本、区域级变化、接受或拒绝、最终确认版本 |

匿名化患者 ID 用于数据划分：同一患者的多个牙位、重复扫描、同一修复体的不同版本必须落在同一个数据集划分中（见 [03 实验协议](03-experiment-protocol.md)）。

单个坐标点没有独立语义，不作为学习样本。

### 1.1 标准病例设计的附加字段

标准病例设计中，多位牙技师从同一个 `S_0` 出发修正同一个病例。附加字段：

| 层级 | 字段 | 内容 |
|---|---|---|
| Case | `standard_case_id` | 标准病例 ID；同一标准病例的所有会话共享 |
| Case | `s0_hash` | `S_0` 文件哈希，用来确认所有会话的起点完全相同 |
| Case | `contributed_by` | 提供该病例的牙技师匿名 ID（没有则为空） |
| Case | `selection_tags` | 选择标准对应的标签：牙位类别、边缘位置（龈上 / 平龈 / 龈下）、AI 初始误差等级 |
| Session | `technician_id` | 牙技师匿名 ID |
| Session | `software_version` | 3Shape 软件版本 |
| Session | `order_index` | 该牙技师的第几个会话（用于检查顺序效应） |
| Session | `is_repeat` / `repeat_of` | 是否为重复会话，及对应的主会话 ID |
| Session | `own_case` | 修正的是否为该牙技师自己提供的病例 |
| Session | `duration` | 会话开始到确认交付的时间 |

同一标准病例的所有会话以同一个 `S_0` 作为区域参考（第 6.3 节），因此不同牙技师的 Final GD 可以按区域直接比较。

## 2. 三种粒度

| 粒度 | 例子 | 能否独立作为学习样本 |
|---|---|---|
| 输入事件 | 一次鼠标移动、一次点击 | 不能，没有语义 |
| 编辑动作 | 拖动 margin line 上的一个控制点 | 很少能，一个意图常常要多个动作 |
| 修正意图 | 「把远中颊侧这一段往龈方降低」 | 能，但需要结合日志与人工核对才能确认 |

## 3. 三个独立概念

「改变发生了」和「改变是正确的」是两件事。来回调整后只留下很小净变化的操作，可能是一次重要的精细修正；被保留的大幅移动，也不一定是质量改善。因此分成三个概念：

| 概念 | 回答的问题 | 怎样得到 | 可信度来源 |
|---|---|---|---|
| Geometry Delta（GD） | 两个确定版本之间实际改变了什么？ | 几何算法计算 | 对应关系质量（第 9 节） |
| Correction Episode（CE） | 牙技师在一个连续任务中尝试了哪些修改？ | 动作日志 + 切分规则 + 人工核对 | 切分与人工标注的一致性 |
| Validated Improvement（VI） | 有独立证据支持这次修改改善了预先定义的目标吗？ | 专家参考、质量指标、后续结果 | 证据的独立性与评价标准版本 |

三者之间的关系：

- 一个 CE 可能产生零个、一个或多个区域的 GD。
- GD 不能证明 VI。没有 VI 证据的 GD 状态是「未验证」，不是「正确」。
- 三者通过第 6 节的数据链连接，可以完整重放。

## 4. Geometry Delta

**定义**：同一设计对象在两个确定版本之间的几何差异，按区域记录。

GD 可以在不同的版本对之间计算，用途不同：

| 类型 | 版本对 | 用途 |
|---|---|---|
| Step GD | 相邻两个版本 `S_k → S_k+1` | 单个动作或检查点改变了什么 |
| Episode GD | CE 开始版本 → CE 结束版本 | 一次修正任务的净效果 |
| Final GD | `S_0` → `S_final` | 学习目标 T1 / T2 的标签（第 8 节） |

- GD 只描述「变了什么」，不涉及意图，也不评价好坏。
- 噪声阈值只用来区分「测量上有没有变化」，不用来判断修改是否重要。
- 位移分析只在对应状态为 MATCHED 的区域进行（第 9 节）。

描述符：

| 字段 | 内容 |
|---|---|
| `gd_type` | step / episode / final |
| `object` | 设计对象，如 margin line |
| `from_version` / `to_version` | 两个几何版本的 ID |
| `region` | 归一化弧长区间 `[t1, t2]`（以 `S_0` 为参考，见第 6.3 节） |
| `correspondence` | MATCHED / AMBIGUOUS / UNMATCHED，及检查结果 |
| `displacement` | 局部坐标系下的位移分量（仅 MATCHED 区域） |
| `magnitude` | 最大与平均位移（μm，仅 MATCHED 区域） |
| `profile` | 区间内位移形状（可用低阶样条压缩） |
| `surface_fit` | 两个版本曲线各自的表面贴合检查结果（第 10.3 节） |
| `sector` | 解剖分区（颊 / 舌 / 近中 / 远中），在 `S_0` 上按参考轴划分；用于跨病例比较。划分方法版本化（[待决问题](open-questions.md) Q17） |
| `context` | 局部曲率、扫描质量、预备体类型、牙位 |
| `frame_version` | 局部坐标系的定义版本 |

## 5. Correction Episode

**定义**：牙技师在一个连续任务中，针对一个设计对象进行的全部修改尝试，包括最终保留的、被覆盖的和被撤销的修改。

切分规则（可版本化）：

- **开始**：激活编辑工具后第一次产生几何变化的时刻。
- **结束**（任一条件）：确认 / 保存、切换对象或工具、超过空闲阈值。
- **区域划分**：Episode 内部按曲线区域划分子段；一次连续拖动跨越两个不相邻区域时，按区域拆开。
- **合并**：同一区域内被视角操作隔开的多次编辑，属于同一子段。

人工核对：抽样 Episode 由牙技师或专家标注修正意图（区域、方向、原因）。意图标签只来自人工，不由模型自动推断后直接写入。

所有阈值（空闲时间、区域距离、位移噪声）记录在规则版本中。更换规则版本后，Evaluation Harness 必须能重放历史数据并比较切分差异。

## 6. 数据链：动作、中间版本、区域与 GD

只看 Final GD 会丢失过程。例如：

```
S_0 ──(Episode 1：某段向龈方移动 200 μm)──▶ S_1
S_1 ──(Episode 2：同一段反向调整 180 μm)──▶ S_2 = S_final
```

Final GD 只剩约 20 μm，但 CE 记录了两次方向相反的尝试。数据链要保证这两次尝试各自的方向、幅度和去向都能被重放。

### 6.1 版本图

- 每次产生几何变化的动作（或检查点，见第 6.5 节）生成一个新的不可变版本节点 `S_k`，记录父版本 `parent`。
- **撤销不删除版本**：undo 生成一个新节点，标记 `reverts_to = S_j`（恢复到的版本），几何内容与 `S_j` 相同。
- 重新编辑从当前节点继续，不覆盖历史节点。
- 版本图因此是一条可回放的链；分支只在 CAD 软件本身支持分支时出现。

### 6.2 动作—版本关联

每个编辑动作记录：

| 字段 | 内容 |
|---|---|
| `action_id` | 动作 ID |
| `episode_id` | 所属 CE |
| `object` | 被编辑的设计对象 |
| `tool` / `params` | 使用的 CAD 工具及参数 |
| `from_version` / `to_version` | 动作前后的版本 |
| `regions` | 受影响的区域列表（一个动作可影响多个区域） |
| `step_gd` | 每个受影响区域的 Step GD 记录 ID |
| `capture_level` | 该动作的采集粒度 |

一个动作影响多个区域时，每个区域各自生成一条 Step GD，引用同一个 `action_id`。

### 6.3 区域参考

- 所有区域统一用 `S_0` 的归一化弧长参数表示，这样不同版本、不同 Episode 的区域可以直接比较。
- 每个中间版本同时与两个版本建立对应：**相邻版本**（用于 Step GD）和 **`S_0`**（用于统一区域参考）。
- 不通过连续串联相邻对应来推算与 `S_0` 的对应，因为误差会累积。
- 两条路径得到的区域位置不一致（超过阈值）时，该区域标记为 AMBIGUOUS。

### 6.4 动作的去向

每个动作在每个受影响区域的去向，通过比较它的 Step GD 和之后同一区域的变化来判定：

| 去向 | 判定 | 用途 |
|---|---|---|
| 保留 | 该动作的变化在 `S_final` 中基本仍然存在 | 与 Final GD 关联 |
| 部分保留 | 后续动作在同一区域抵消了其中一部分 | 研究精细调整；上例中 Episode 1 属于此类 |
| 被覆盖 | 后续动作在同一区域替代了它的变化 | 研究修正策略 |
| 撤销 | 版本图中存在 `reverts_to` 指回该动作之前的版本 | 犹豫或试探信号 |
| 探索性 | 视角操作、低于阈值的往复微调 | 过程特征；往复微调可能是精细修正，不丢弃 |
| AI 建议被拒绝 | 系统提出、牙技师拒绝 | 单独存档，避免重复推荐 |

「保留 / 部分保留 / 被覆盖」的候选判定方法：在 MATCHED 区域内，计算该动作之后到 `S_final` 的累计位移在该动作位移方向上的投影，与该动作位移幅度之比。具体分界值在阶段 1 用人工标注校准，并版本化。非 MATCHED 区域只记录「发生过修改」，不判定保留比例。

### 6.5 采集粒度等级

数据链能做到多细，取决于 CAD 软件能暴露什么（[待决问题](open-questions.md) Q1）。每个会话记录它的采集粒度：

| 等级 | 能获得的几何状态 | 支持的分析 |
|---|---|---|
| C3 · 动作级 | 每个编辑动作后的几何 | 完整数据链；Step GD；动作去向 |
| C2 · 检查点级 | 保存、确认或定时快照时的几何 | Episode GD；去向只能判定到检查点之间 |
| C1 · 仅首尾 | 只有 `S_0` 和 `S_final` | 只有 Final GD；CE 只能来自操作日志，不能关联几何 |
| C0 · 无几何 | 只有屏幕录像或鼠标轨迹 | 不能产生 GD 标签；只能用于 H1 中「仅轨迹」组的研究 |

分析时按采集粒度筛选数据，不把低粒度会话混入需要高粒度的分析。

## 7. Validated Improvement

**定义**：针对某个 GD，记录是否有独立证据表明它改善了**预先定义**的目标。

| 字段 | 内容 |
|---|---|
| `target_gd` | 关联的 GD |
| `criterion` | 评价标准 ID 与版本 |
| `evidence_type` | 几何有效性 / 预定义标准 / 专业评价 / 生产结果（见第 12 节） |
| `evidence_source` | 证据来源；必须独立于做出该修改的牙技师 |
| `result` | 改善 / 无差异 / 变差 / 无法判断 |
| `reviewed_at` | 评价时间 |

规则：

- 评价标准必须在评价之前定义并版本化。
- 做出修改的牙技师自己确认设计，不构成 VI 证据。
- 没有 VI 记录的修改，只能用于「偏好」类问题，不能用于「质量改善」类结论。

## 8. 学习目标

| 目标 | 内容 | 标签来源 |
|---|---|---|
| T1 · 区域 | 当前设计中哪些区域会被修改 | Final GD 中有可测变化的区域 |
| T2 · 局部变化 | 被修改区域的方向与幅度 | MATCHED 区域的 Final GD 位移 |
| T3 · 接受结果 | 某个候选修改会不会被这位牙技师接受 | 真实的建议接受 / 拒绝记录 |

**建议的第一版目标**：T1 + T2，即预测这位牙技师最终确认的设计相对 AI 初始设计的区域与局部变化。

- 最终确认设计是**个人偏好**的参考标签，不是独立的质量标签。
- T3 只能来自真实展示过的建议及其反馈，不能从最终几何推算（见 [03 实验协议](03-experiment-protocol.md)）。
- 修改意图（CE 的人工标注）在第一版只用于验证切分和解释误差，不作为模型目标。
- Step GD 和动作去向在第一版用于 H1 和误差分析，不作为预测目标。
- 最终选择记录在 [待决问题](open-questions.md) Q7。

## 9. 曲线对应关系（独立的几何子问题）

修改前后曲线之间不保证存在一一对应。局部大幅重画、形态变化、投影歧义，都可能导致两个最终点对应到初始曲线的相近位置，或者把不相关的位置错配在一起。

按区域输出三种状态：

| 状态 | 含义 | 下游处理 |
|---|---|---|
| MATCHED | 满足全部一致性标准 | 进入位移分析 |
| AMBIGUOUS | 存在多个合理对应，或部分标准未通过 | 只记录区域级变化，不计算逐点位移 |
| UNMATCHED | 找不到满足标准的对应 | 只保存修改前后的原始几何 |

候选一致性标准（阈值待定）：

1. **投影距离**：对应点之间的距离在上限以内。
2. **顺序保持**：对应关系保持弧长方向的单调性，不出现折返。
3. **单射**：不存在多个最终点映射到初始曲线上过近的位置。
4. **切向一致**：对应点的曲线切向夹角在上限以内。
5. **局部稳定**：对投影参数做小扰动，对应结果不发生跳变。
6. **路径一致**：经相邻版本与直接对 `S_0` 两条路径得到的位置一致（第 6.3 节）。

投影加弧长重采样只是候选方法之一。无论用哪种方法，都必须输出上面的状态，且同一组标准能在 Evaluation Harness 中复现。

**原则**：AMBIGUOUS 和 UNMATCHED 区域保留原始状态和最终状态，但系统不能假装知道每个点是怎样移动过去的。

## 10. 局部坐标系

### 10.1 定义

在初始曲线的每个采样点 `p`：

- `t`：曲线单位切向。
- `n`：网格在 `p` 附近一定半径内平滑后的表面法向。
- `b = n × t`：位于 `p` 处牙面切平面内、垂直于曲线的方向。

位移 `d`（对应点之间的直线位移）分解为：

| 分量 | 计算 | 含义 |
|---|---|---|
| 切向 | `d · t` | 沿曲线方向的移动 |
| 横向 | `d · b` | 在 `p` 处切平面内垂直于曲线的移动 |
| 法向 | `d · n` | 沿 `p` 处法向的移动 |

### 10.2 法向分量不是质量判据

即使修改前后的曲线都贴在同一个牙面上，牙面有曲率时，沿曲面移动的直线位移相对 `p` 处法向也会有非零分量，且随位移幅度和局部曲率增大。因此：

- `d · n` 只作为位移分解的一个分量记录，**不用来判断是否发生了不合理的离面移动**。
- 当 `|d|` 相对局部曲率半径不再很小时，切平面分解的解释力下降；这类点标记为「大位移」，分析时单独处理。必要时改用沿表面的测地路径描述位移（候选方法，待评估）。

### 10.3 表面贴合检查（独立于位移分解）

对每个版本的曲线**单独**检查它是否贴合目标网格：

- 曲线采样点到网格表面的最近距离（点到面距离）的分布：最大值、高分位数。
- 投影残差：把曲线投影到网格后与原曲线的偏差。

贴合检查的阈值属于几何有效性标准（第 12 节），与位移分解无关。

### 10.4 冠方 / 龈方的符号

由参考轴决定，而不是由法向决定：

- 参考轴 `a`：修复体就位道方向，或者预备体长轴。
- `d · b` 与 `a · b` 同号记为冠方，反号记为龈方。
- 当 `|a · b|` 低于阈值时，该点的冠方 / 龈方标记为「不确定」，只保留数值分量。
- 参考轴的来源见 [待决问题](open-questions.md) Q8。

### 10.5 参数敏感性

法向受网格噪声、平滑半径和网格方向影响。阶段 1 必须检验（[03](03-experiment-protocol.md)）：

- 平滑半径、参考轴在合理范围内小幅变化时，T2 标签中冠方 / 龈方符号的翻转比例、幅度的变化量。
- 对网格做轻度重采样或加入扫描量级噪声后，上述标签的稳定性。

敏感性过高的区域标记为不稳定，不进入 T2 训练与评估。坐标系定义或参数变更时，递增 `frame_version`。

## 11. 参数化

- 用弧长参数化曲线，以解剖标志点（近中、颊侧、远中、舌侧中点）为锚点，将参数归一化到 `[0, 1)`。
- 这样「远中颊侧那一段」在不同病例中对应大致相同的参数区间，检索和统计才有意义。
- 标志点的定位方法与不确定性需要单独记录。

## 12. 结果记录与质量证据

### 12.1 每个设计版本的结果记录

| 字段 | 取值 |
|---|---|
| `geometry_confirmed` | 几何状态是否经过牙技师确认（是 / 否），及确认时间 |
| `independent_review` | 是否有独立专家复核（无 / 有），复核人匿名 ID，是否盲于组别，复核结论 |
| `manufactured` | 是否已制造（是 / 否 / 未知） |
| `post_adjustment` | 后续调整（无 / 椅旁调整 / 重做 / 未知），及记录到的原因与部位 |
| `criteria_results` | 每条预定义评价标准的结果（通过 / 未通过 / 未评价），附标准版本 |

没有返工记录不代表所有设计目标都已满足；发生返工也不代表原始设计在所有方面都是错误的。

### 12.2 四类质量证据

它们可以互相补充，但**不能互相替代**：

| 证据 | 回答的问题 | 来源 |
|---|---|---|
| 几何有效性 | 曲线、网格、坐标变换和对应关系本身是否可靠？ | 表面贴合检查、对应状态、参数敏感性 |
| 预定义标准 | 是否满足事先确定的几何检查？ | `criteria_results` |
| 专业评价 | 独立专家是否认为设计满足指定评价标准？ | `independent_review` |
| 生产结果 | 是否制造、返工或发生后续调整？ | `manufactured`、`post_adjustment` |

几何有效性不通过时，该记录的其他几何分析不可信，先排除。几何检查通过不自动证明临床或制造质量合格。

### 12.3 数据集准入

| 用途 | 最低要求 |
|---|---|
| 偏好训练与评估（T1 / T2） | `geometry_confirmed = 是`；几何有效性通过；采集粒度 ≥ C1 |
| H0 个人差异分析 | 同 T1 / T2；另需 `standard_case_id`、`s0_hash` 一致；`sector` 已划分 |
| H1 与动作去向分析 | 采集粒度 ≥ C2（动作去向需要 C3） |
| 质量相关结论 | 另外要求有专业评价或相关预定义标准已评价 |
| 返工分析 | `post_adjustment` 已知，并结合记录到的原因与部位 |

## 13. 贝塞尔曲线的位置

作为**候选表示**接受检验，不默认采用：

- **过程侧**：拟合 CE 中的拖动轨迹，提取平滑度、曲率、速度特征，作为 H1「仅轨迹」组的候选特征。
- **结果侧**：压缩 GD 的位移 `profile`。

评价标准：重建误差，以及对下游任务有无额外价值。如果原始数据基线效果一样好，就不保留。

## 14. 版本规则

- 病例、网格、曲线每次变化生成不可变版本；动作、Episode、GD、VI 都引用版本 ID，而不是可变对象。
- 切分规则、去向判定、对应关系标准、坐标系定义、评价标准分别版本化。
- 规范本身的变更递增版本号，并在本文件顶部注明。
