# 02 · 数据规范

版本：v0.2 草案（v0.2 新增第 3–9 节：「有效修正」的定义与表示）

数据结构先于模型设计。

## 1. 数据层级

| 层级 | 内容 |
|---|---|
| Case · 病例 | 修复体类别、牙位、匿名化 ID、扫描和网格版本 |
| Session · 建模会话 | 软件状态、时间、相机视角、操作工具及病例状态变化 |
| Episode · 修正任务 | 一次完整的修正任务，例如从初始 margin line 开始修改，直至牙技师确认或取消 |
| Evidence · 事件与证据 | 轨迹采样、几何变化、操作原因、接受或拒绝、最终确认版本 |

一个 Episode 的典型过程：选择 margin line 编辑工具 → 调整一段边缘线 → 旋转视角检查连续性 → 再次修改局部 → 确认最终结果。单个坐标点没有独立语义，不作为学习样本。

## 2. 两类结果必须分开保存

- **最终确认结果**：用于建立高质量学习标签。
- **尝试及失败记录**：用于研究修正策略，不能直接当作正确答案。

被拒绝的 AI 建议单独存档，避免系统反复推荐已被否定的修改。

## 3. 为什么要定义「有效修正」

「修正」混着三种粒度：

| 粒度 | 例子 | 能否独立作为学习样本 |
|---|---|---|
| 输入事件 | 一次鼠标移动、一次点击 | 不能，没有语义 |
| 编辑动作 | 拖动 margin line 上的一个控制点 | 很少能，一个意图常常要多个动作 |
| 修正意图 | 「把远中颊侧这一段往龈方降低」 | 能，这是要学习的单位 |

「有效修正」定义在意图层，但必须能从下面两层的记录**自动推出**，并且能被人工核对。

## 4. 定义

**有效修正（Effective Correction, EC）**：在一个 Episode 内，针对**同一设计对象**的**同一局部区域**做出的、**保留到最终确认版本**、且**幅度超过噪声阈值**的净几何改变。

必须满足的条件：

1. **可归属**：几何变化能定位到具体对象（如 margin line）和具体区域（如一段弧长区间）。
2. **持久**：改变在最终确认的设计中仍然存在，未被后续操作覆盖或撤销。
3. **非平凡**：位移超过阈值。阈值参考扫描精度和工具吸附误差确定；视角操作一律不算。
4. **有边界**：有明确的开始和结束（见第 7 节）。

不满足条件的操作不丢弃，归入其他类别：

| 类别 | 判定 | 用途 |
|---|---|---|
| 有效修正 | 四个条件均满足 | 主要学习标签（改什么） |
| 被覆盖的修正 | 发生过，但被同一区域的后续修改替代 | 研究修正策略，不当作正确答案 |
| 撤销的修正 | 被 undo 或手动恢复 | 负样本或犹豫信号 |
| 探索性操作 | 低于阈值的反复微调、只改视角 | 过程特征 |
| 被拒绝的 AI 建议 | 系统提出、牙技师拒绝 | 单独存档 |

## 5. 结果与过程分离

- **结果（What）**：最终确认状态 `S_final` 与初始状态 `S_0`（AI 初始设计）在该区域内的**净差异**。这是 H2 / H3 / H4 的预测目标。
- **过程（How）**：从 `S_0` 到 `S_final` 的完整轨迹，包括动作序列、停顿、视角切换、反复调整。这是 H1 的研究对象。

即使轨迹建模失败，结果标签仍然成立，H2 / H3 的实验不受影响。

## 6. margin line 的表示

### 6.1 参数化

- 用弧长参数化曲线，以解剖标志点（近中、颊侧、远中、舌侧中点）为锚点，将参数归一化到 `[0, 1)`。
- 使「远中颊侧那一段」在不同病例中对应大致相同的参数区间，检索和统计才有意义。

### 6.2 前后对应

- 将修改后的曲线投影回修改前的曲线，按弧长重采样，建立一一对应。
- 对应关系有歧义时（例如局部被大幅重画），该 EC 标记为「低可信对应」。

### 6.3 位移场

每个采样点的位移分解为：

- 沿牙面法向的分量（冠方 / 龈方）
- 沿曲线切向的分量（滑移）
- 离开网格表面的分量（理论上接近 0，作为质量检查项）

### 6.4 EC 描述符

| 字段 | 内容 |
|---|---|
| `region` | 归一化弧长区间 `[t1, t2]` |
| `direction` | 主方向：冠方 / 龈方 / 切向 |
| `magnitude` | 最大位移与平均位移（μm） |
| `profile` | 区间内位移曲线形状（可用低阶样条压缩） |
| `context` | 局部曲率、扫描质量、预备体类型、牙位 |
| `provenance` | 来源动作、是否参考过 AI 建议 |
| `label_strength` | 标签强度（见第 8 节） |
| `rule_version` | 生成该 EC 的切分规则版本 |

## 7. 切分规则

- **开始**：激活编辑工具后第一次产生几何变化的时刻。
- **结束**（任一条件）：确认 / 保存、切换对象或工具、超过空闲阈值、在曲线上离开当前区域足够远。
- **合并**：同一区域内被视角操作隔开的多次编辑合并为一个 EC。
- **拆分**：一次连续拖动跨越两个不相邻区域时，按区域拆开。

所有阈值（空闲时间、区域距离、位移噪声）记录在规则版本中。更换规则版本后，Evaluation Harness 必须能重放历史数据并比较切分差异。

## 8. 标签强度

| 等级 | 条件 |
|---|---|
| 强 | 设计已确认、已制造，且无返工记录 |
| 中 | 设计已确认，但缺少制造或返工信息 |
| 弱 | 会话中途结束、对应关系低可信，或只有过程数据 |

训练与评估默认只使用强、中标签；弱标签只用于辅助分析。

## 9. 贝塞尔曲线的位置

作为**候选表示**接受检验，不默认采用：

- **过程侧**：拟合拖动轨迹，提取平滑度、曲率、速度特征，用于检验 H1。
- **结果侧**：压缩位移 `profile`。

两种用法的评价标准：重建误差，以及对下游任务（意图识别、修正预测）有无额外价值。如果原始数据基线效果一样好，就不保留。

## 10. 版本规则

- 病例、网格、曲线每次变化生成不可变版本，Episode 引用版本 ID 而非可变对象。
- 规范本身的变更（字段、阈值、规则）递增版本号，并在本文件顶部注明。
