# 审查记录 · H1 输入与标签独立性

日期：2026-10-21
状态：**待决议提案**。本文件只存档分析和候选方案，尚未修改 [03 实验协议](../03-experiment-protocol.md) 的正文。
基于版本：实验协议 v0.4、数据规范 v0.5（提交 `02dd900`）

## 1. 问题

H1 的主要终点是离线动作去向分类的宏平均 F1（实验协议 §4.2）。标注者虽然看不到规则输出，但融合组可以访问完整会话内的 CAD 事件与几何变化，而去向标签在定义上就是由这些信息决定的。此时宏平均 F1 衡量的是「标签在多大程度上是输入的确定性函数」，而不是识别能力；「融合优于仅轨迹」在实验之前就几乎可以预料到，H1 失去了被反驳的可能。

## 2. 输入分层

| 层 | 内容 | 仅轨迹组 | 融合组 |
|---|---|---|---|
| F0 | 鼠标轨迹、时间 | ✓ | ✓ |
| F1 | CAD 事件：工具、对象、视角、undo / redo、保存 / 确认 | — | ✓ |
| F2 | 该动作自身的 Step GD | — | ✓ |
| F3 | 该动作之后的 Step GD，直到 `S_final` | — | ✓ |

注意：键盘触发的 undo 等事件属于 F1，不属于轨迹。仅轨迹组必须排除键盘事件，否则两组都会泄漏。

## 3. 类别与输入层的定义性依赖

| 去向 | 定义依赖 | 融合组能否用规则直接重建 |
|---|---|---|
| 撤销 | F1 的 undo 事件、版本图 `reverts_to` | 几乎可以，查事件即可 |
| 保留 / 部分保留 / 被覆盖 | F2 + F3：后续累计位移在本动作方向上的投影比例（数据规范 §6.4） | 可以 |
| 探索性 | F1（视角操作）+ F2（低于阈值） | 大部分可以 |

## 4. 泄漏量化（评估前完成，只用校准子集）

1. 对每个类别，只用确定性规则（不训练），分别从 F1、F1+F2、F1+F2+F3 计算标签，与人工标签比较 F1。
2. 与标注者之间的一致性对照：规则对人工的一致性接近人与人之间的一致性时，该类别在该输入层上是**定义性标签**。
3. 结果登记为「类别 × 输入层」泄漏表。

## 5. 候选方案

| 方案 | 做法 | 优点 | 代价 |
|---|---|---|---|
| A · 改主要终点 | 主要终点改为**修正意图**分类（例如纠错 / 精细调整 / 试探后放弃 / 检查性操作）。意图标签来自会话后与牙技师的回放访谈或有声思维记录，两组都无法访问这些来源 | 几何成为意图的证据而非定义，H1 可被反驳 | 标注成本高；需要牙技师配合；意图类别需先验证人与人一致性 |
| B · 保留去向，改对照 | 主要终点仍为去向宏 F1，但融合组的基线改为确定性规则，H1 只看相对规则的增量；定义性类别按泄漏表排除或单独报告 | 改动小，不需要新的标注来源 | 剩下的非定义性类别可能很少，增量可能难以检出 |
| C · 截断输入 | 融合组只能使用动作结束后固定时间窗内的信息，不能使用 F3 全程 | 直接切断重建路径 | 任务变成「预测」，与「离线识别」的任务定义冲突 |

## 6. 建议

采用 **A + B**，不采用 C：

- 动作去向识别降为**数据链验证**：规则对人工的一致性放进阶段 1 的可观测性检查，作为 H1 的前提，不作为 H1 的证据。
- H1 主要终点改为修正意图分类的宏平均 F1；两组都不能访问意图标签的来源。
- 第 4 节的泄漏表作为登记材料，证明意图标签不是输入的确定性函数：规则重建意图标签的一致性，应明显低于人与人之间的一致性。

## 8. 同轮已确认、待下次修订时写入的内容

硬性失败条件的表述改为：

> 硬性失败条件必须能够依据该版本自身的几何数据及其必要的参考对象独立判定，不依赖修改前后曲线的对应关系。

并为每条硬性规则记录规则 ID、版本、检测结果及失败原因；输入数据本身损坏时，记为不可评价，不能把算法无法判断当作设计失败。各检查项的独立性：

| 检查项目 | 能否独立于跨版本对应 | 备注 |
|---|---|---|
| 曲线未闭合 | 可以 | 先确认任务要求闭合曲线 |
| 曲线自交 | 可以 | 固定检测容差和数值稳健性规则 |
| 表面贴合 | 可以 | 需要当前版本曲线、目标网格及可靠的空间配准 |
| 修改前后位移异常 | 通常不可以 | 依赖跨版本对应，与单版本硬性失败分开 |
