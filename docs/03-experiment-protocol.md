# 03 · 实验协议

版本：v0.1 草案

不直接测试一个「完整 AI 牙技师」，而是分三个阶段，每个阶段都有停止条件。

## 通用规则

- **按独立病例划分**训练集与测试集，不随机拆分同一病例内的轨迹点或片段。否则系统可能只是记住了病例，而不是学会泛化。
- 研究个人适应性（H3）时，测试集同时按牙技师和病例划分，并记录每位牙技师的样本量。
- 指标阈值、非劣效界限、时间收益目标在实验开始前登记，不事后调整。

## 阶段 1 · 可观测性实验（H1）

研究真实操作能否被完整记录，并映射到实际几何变化。

**主要指标**：事件记录完整率、事件切分准确率、三维映射误差、几何差异的可重复性。

**「有效修正」定义的验证**（见 [02 数据规范](02-data-specification.md)）：

1. 选 20–30 个会话，由两位牙技师或专家独立人工标注修正边界和意图。
2. 人与人一致性：意图类别用 Cohen's κ，边界用带时间容差的 F1。人与人之间都不一致时，先修改定义，不进入训练。
3. 自动切分与人工标注比较，达到预设门槛才进入阶段 2。
4. 稳健性：小幅调整阈值，观察 EC 数量和描述符是否稳定。

**停止条件**：无法可靠获得修改前后状态时，先不研究预测，因为学习标签不可信。

## 阶段 2 · 经验可复用性实验（H2、H3）

在新病例上比较三种方法：

| 组别 | 方法 |
|---|---|
| A | 不使用经验（现有 AI 初始设计） |
| B | 检索历史案例（L2 基线） |
| C | 个人模型建议 |

**主要指标**：建议接受率、局部几何误差、编辑时间、返工次数。

**停止条件**：案例检索没有稳定收益时，先检查特征表示、病例相似度和标签质量，不急着增加模型复杂度。

## 阶段 3 · 生产价值实验（H4）

在代表性病例上比较现有工作流与辅助系统，确认使用系统后没有增加错误或返工。

**主要指标**：每例主动编辑时间、总完成时间、最终几何质量、人工拒绝率。

**通过条件**：事先设定质量非劣效界限和时间收益目标，并在未用于训练的病例上验证。几何检查通过不等于临床或制造质量自动达标。
