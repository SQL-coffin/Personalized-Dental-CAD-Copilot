# 04 · 风险与治理规范

版本：v0.1 框架（各节内容待随数据来源和合作方确定后补全）

## 1. 患者数据保护

- 病例在进入数据层前完成匿名化，只保留匿名化 ID。
- 扫描网格本身可能带有可识别信息，存储、访问和导出都需要权限控制。
- 适用的法规与合作方协议待确认（取决于数据来源地区）。

## 2. 操作权限

- 预测/推理层只能提出候选修改，不能直接写入最终几何。
- 所有写操作经 Runtime Harness 的工具注册与参数校验。
- 权限分级：只读分析 → 生成建议 → 经批准后执行。

## 3. 人工审批

- 任何会改变设计的建议都需要牙技师明确批准。
- 批准、拒绝及其理由都记录为 Evidence。
- 系统不对设计做最终放行。

## 4. 撤销机制

- 每次执行前保存不可变版本，支持一步回滚到执行前状态。
- 回滚本身作为事件记录，用于后续分析。

## 5. 错误建议处理

- 被拒绝的建议单独存档，相似情境下抑制重复推荐。
- 证据不足时输出「无法可靠判断」，而不是给出低质量建议。
- 定期在 Evaluation Harness 中回放被拒绝和被回滚的案例，进行失败分析。

## 6. 已知风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| CAD 软件不暴露几何状态 | 修改前后状态不可信，标签失效 | 阶段 1 先验证可观测性；不满足即停止 |
| 单个牙技师样本量过小 | H3 无法得出统计结论 | 预先估计样本需求，必要时调整研究范围 |
| 个人偏好与临床质量冲突 | 系统强化不良习惯 | 质量非劣效检查独立于个人偏好 |
| 数据泄漏（同一病例进入训练和测试） | 高估泛化能力 | 严格按病例划分 |
