# Personalized Dental CAD Copilot

个性化牙科 CAD 智能系统（暂定名：Personalized Dental CAD Intelligence）。

> 当前阶段：**研究设计**。暂不写实现代码，也不绑定具体的 AI 模型或牙科 CAD 软件。

## 核心假设

如果系统能够记录牙技师面对初始设计时的修改行为，并将这些行为与三维几何变化、任务上下文和最终确认结果联系起来，那么它就可能逐渐学习到个人的设计偏好和修正策略，从而减少未来相似病例的人工调整时间。

这是一个**需要通过实验验证的假设**，不是已经成立的结论。

## 当前优先级

不继续扩展算法路线，先把关键定义固定下来：

| 优先级 | 工作 | 主要文件 |
|---|---|---|
| P0 | 定义学习目标：分开几何变化、修正任务和经过验证的改善；明确模型预测什么 | 02 |
| P1 | 明确数据可观测性：可信的初始 / 最终曲线、CAD 状态与操作记录；对应关系的不确定性标签 | 02、03 |
| P2 | 设计公平对照实验：通用、记忆、学习三种基线；提前定义测试集和成功标准 | 03 |
| P3 | 完成执行治理：只读、建议、确认后执行三级权限；回滚与审计 | 04 |

正式实验前还必须完成：数据来源与合作方授权、适用的数据保护法规、2025 年 margin line 研究的完整引用（见 [待决问题](docs/open-questions.md)）。

## 原则

- 设计先于代码：代码实现已经明确的设计，而不是由零散代码决定项目方向。
- 「改变发生了」不等于「改变是正确的」；个人偏好不等于设计质量。
- 推理必须可验证：保留可检查的证据、候选方案、工具调用记录和验证结果，而不是依赖模型的自我解释。
- 几何计算与 AI 推理分离：三维几何由确定性算法计算和验证。
- 证据不足时，系统应输出「无法可靠判断」。
