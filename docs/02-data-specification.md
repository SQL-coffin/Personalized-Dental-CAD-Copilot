# 02 · 数据规范

版本：v0.3 草案

v0.3 变更：
- 原「有效修正（Effective Correction）」拆分为三个独立概念：Geometry Delta、Correction Episode、Validated Improvement（第 3–6 节）。
- 明确学习目标（第 7 节）。
- 曲线对应关系定义为独立的几何子问题，结果分为 MATCHED / AMBIGUOUS / UNMATCHED（第 8 节）。
- 明确局部坐标系的建立方法（第 9 节）。
- 用多字段的结果记录取代强 / 中 / 弱单一标签等级（第 11 节）。

数据结构先于模型设计。

## 1. 数据层级

| 层级 | 内容 |
|---|---|
| Case · 病例 | 修复体类别、牙位、匿名化 ID、扫描和网格版本 |
| Session · 建模会话 | 软件状态、时间、相机视角、操作工具及病例状态变化 |
| Episode · 修正任务 | 一次连续的修正任务（定义见第 5 节） |
| Evidence · 事件与证据 | 轨迹采样、几何变化、操作原因、接受或拒绝、最终确认版本 |

单个坐标点没有独立语义，不作为学习样本。

## 2. 三种粒度

| 粒度 | 例子 | 能否独立作为学习样本 |
|---|---|---|
| 输入事件 | 一次鼠标移动、一次点击 | 不能，没有语义 |
| 编辑动作 | 拖动 margin line 上的一个控制点 | 很少能，一个意图常常要多个动作 |
| 修正意图 | 「把远中颊侧这一段往龈方降低」 | 能，但需要结合日志与人工核对才能确认 |

## 3. 三个独立概念

v0.2 把「同一区域内、超过噪声阈值、保留到最终版本的净几何改变」直接定义为有效修正。这个定义便于计算，但混淆了两件事：**改变发生了**，以及**改变是正确的**。

- 来回调整后只留下很小净变化的操作，可能是一次重要的精细修正。
- 被保留的大幅移动，不一定是质量改善。

因此 v0.3 分成三个概念，分别回答不同的问题：

| 概念 | 回答的问题 | 怎样得到 | 可信度来源 |
|---|---|---|---|
| Geometry Delta（GD） | 最终状态与初始状态之间，实际改变了什么？ | 几何算法计算 | 对应关系质量（第 8 节） |
| Correction Episode（CE） | 牙技师在一个连续任务中尝试了哪些修改？ | 操作日志 + 切分规则 + 人工核对 | 切分与人工标注的一致性 |
| Validated Improvement（VI） | 有独立证据支持这次修改改善了预先定义的目标吗？ | 专家参考、质量指标、后续结果 | 证据的独立性与评价标准版本 |

三者之间的关系：

- 一个 CE 可能产生零个、一个或多个区域的 GD。
- GD 不能证明 VI。只有 VI 记录中有独立证据时，才能说修改带来了改善。
- 某个 GD 没有对应的 VI 证据时，它的状态是「未验证」，不是「正确」。

## 4. Geometry Delta

**定义**：同一设计对象在两个确定版本（通常是 `S_0` 初始 AI 设计和 `S_final` 最终确认设计）之间的几何差异，按区域记录。

- 只描述「变了什么」，不涉及意图，也不评价好坏。
- 噪声阈值只用来区分「测量上有没有变化」，不用来判断修改是否重要。低于阈值的区域记为「无可测变化」，但它所在的 CE 仍然完整保留。
- 位移分析只在对应状态为 MATCHED 的区域进行（第 8 节）。

描述符：

| 字段 | 内容 |
|---|---|
| `object` | 设计对象，如 margin line |
| `from_version` / `to_version` | 两个几何版本的 ID |
| `region` | 归一化弧长区间 `[t1, t2]`（以 `S_0` 为参考） |
| `correspondence` | MATCHED / AMBIGUOUS / UNMATCHED，及检查结果 |
| `displacement` | 局部坐标系下的位移分量（仅 MATCHED 区域） |
| `magnitude` | 最大与平均位移（μm，仅 MATCHED 区域） |
| `profile` | 区间内位移形状（可用低阶样条压缩） |
| `context` | 局部曲率、扫描质量、预备体类型、牙位 |
| `frame_version` | 局部坐标系的定义版本（第 9 节） |

## 5. Correction Episode

**定义**：牙技师在一个连续任务中，针对一个设计对象进行的全部修改尝试，包括最终保留的、被覆盖的和被撤销的修改。

切分规则（可版本化）：

- **开始**：激活编辑工具后第一次产生几何变化的时刻。
- **结束**（任一条件）：确认 / 保存、切换对象或工具、超过空闲阈值。
- **区域划分**：Episode 内部按曲线区域划分子段；一次连续拖动跨越两个不相邻区域时，按区域拆开。
- **合并**：同一区域内被视角操作隔开的多次编辑，属于同一子段。

Episode 内每个动作的去向：

| 去向 | 判定 | 用途 |
|---|---|---|
| 保留 | 影响仍体现在 `S_final` | 与 GD 关联 |
| 被覆盖 | 被同一区域的后续修改替代 | 研究修正策略 |
| 撤销 | 被 undo 或手动恢复 | 犹豫或试探信号 |
| 探索性 | 视角操作、低于阈值的往复微调 | 过程特征；往复微调可能是精细修正，不丢弃 |
| AI 建议被拒绝 | 系统提出、牙技师拒绝 | 单独存档，避免重复推荐 |

人工核对：抽样 Episode 由牙技师或专家标注修正意图（区域、方向、原因）。意图标签只来自人工，不由模型自动推断后直接写入。

所有阈值（空闲时间、区域距离、位移噪声）记录在规则版本中。更换规则版本后，Evaluation Harness 必须能重放历史数据并比较切分差异。

## 6. Validated Improvement

**定义**：针对某个 GD，记录是否有独立证据表明它改善了**预先定义**的目标。

| 字段 | 内容 |
|---|---|
| `target_gd` | 关联的 GD |
| `criterion` | 评价标准 ID 与版本（例如与专家参考线的距离、连续性检查） |
| `evidence_type` | 专家参考 / 几何质量指标 / 制造与后续结果 |
| `evidence_source` | 证据来源；必须独立于做出该修改的牙技师 |
| `result` | 改善 / 无差异 / 变差 / 无法判断 |
| `reviewed_at` | 评价时间 |

规则：

- 评价标准必须在评价之前定义并版本化。
- 做出修改的牙技师自己确认设计，不构成 VI 证据。
- 没有 VI 记录的修改，在评估中只能用于「偏好」类问题，不能用于「质量改善」类结论。

## 7. 学习目标

模型可能预测的目标有三类，它们不是同一个问题：

| 目标 | 内容 | 标签来源 |
|---|---|---|
| T1 · 区域 | 当前设计中哪些区域会被修改 | GD 中有可测变化的区域 |
| T2 · 局部变化 | 被修改区域的方向与幅度 | MATCHED 区域的 GD 位移 |
| T3 · 接受结果 | 某个候选修改会不会被这位牙技师接受 | 建议的接受 / 拒绝记录 |

**建议的第一版目标**：T1 + T2，即预测这位牙技师最终确认的设计相对 AI 初始设计的区域与局部变化。

- 这个目标是「预测个人会怎样改」，属于偏好预测。达成它**不等于**证明质量改善；质量改善要另外由 VI 和实验协议中的 Quality Validation 检验。
- 修改意图（CE 的人工标注）在第一版只用于验证切分和解释误差，不作为模型目标，因为人工标注量有限。
- 最终选择记录在 [待决问题](open-questions.md) Q7。

## 8. 曲线对应关系（独立的几何子问题）

修改前后曲线之间不保证存在一一对应。局部大幅重画、形态变化、投影歧义，都可能导致两个最终点对应到初始曲线的相近位置，或者把不相关的位置错配在一起。

因此对应关系作为单独的几何子问题，按区域输出三种状态：

| 状态 | 含义 | 下游处理 |
|---|---|---|
| MATCHED | 满足全部一致性标准 | 进入位移分析 |
| AMBIGUOUS | 存在多个合理对应，或部分标准未通过 | 只记录区域级变化（例如「此区域被修改」），不计算逐点位移 |
| UNMATCHED | 找不到满足标准的对应 | 只保存修改前后的原始几何 |

候选一致性标准（阈值待定）：

1. **投影距离**：对应点之间的距离在上限以内。
2. **顺序保持**：对应关系保持弧长方向的单调性，不出现折返。
3. **单射**：不存在多个最终点映射到初始曲线上过近的位置。
4. **切向一致**：对应点的曲线切向夹角在上限以内。
5. **局部稳定**：对投影参数做小扰动，对应结果不发生跳变。

投影加弧长重采样只是候选方法之一。无论用哪种方法，都必须输出上面的状态，且同一组标准要能在 Evaluation Harness 中复现。

**原则**：AMBIGUOUS 和 UNMATCHED 区域保留原始状态和最终状态，但系统不能假装知道每个点是怎样移动过去的。

## 9. 局部坐标系

只用牙面法向，不足以表示解剖意义上的冠方或龈方。局部坐标系按以下方式建立：

在初始曲线的每个采样点 `p`：

- `t`：曲线单位切向。
- `n`：网格在 `p` 附近一定半径内平滑后的表面法向。
- `b = n × t`：位于牙面切平面内、垂直于曲线的方向。

位移 `d` 分解为：

| 分量 | 计算 | 含义 |
|---|---|---|
| 切向滑移 | `d · t` | 沿曲线方向的移动 |
| 牙面内横向 | `d · b` | 在牙面上垂直于曲线的移动 |
| 离面 | `d · n` | 离开网格表面的程度；理论上接近 0，作为质量检查项 |

**冠方 / 龈方的符号**由参考轴决定，而不是由法向决定：

- 参考轴 `a`：修复体就位道方向（path of insertion），或者预备体长轴。
- 把 `a` 投影到 `b` 上：`d · b` 与 `a · b` 同号记为冠方，反号记为龈方。
- 当 `|a · b|` 低于阈值（曲线局部几乎与参考轴平行）时，该点的冠方 / 龈方标记为「不确定」，只保留数值分量。

参考轴从哪里来（CAD 软件给出，还是由算法估计）待定，见 [待决问题](open-questions.md) Q8。坐标系定义变更时，递增 `frame_version`。

## 10. 参数化

- 用弧长参数化曲线，以解剖标志点（近中、颊侧、远中、舌侧中点）为锚点，将参数归一化到 `[0, 1)`。
- 这样「远中颊侧那一段」在不同病例中对应大致相同的参数区间，检索和统计才有意义。
- 标志点的定位方法与不确定性需要单独记录。

## 11. 结果记录

不使用单一的强 / 中 / 弱等级。没有返工记录不代表所有设计目标都已满足；发生返工也不代表原始设计在所有方面都是错误的。每个设计版本分别记录：

| 字段 | 取值 |
|---|---|
| `geometry_confirmed` | 几何状态是否经过牙技师确认（是 / 否），及确认时间 |
| `independent_review` | 是否有独立专家复核（无 / 有），复核人匿名 ID，复核结论 |
| `manufactured` | 是否已制造（是 / 否 / 未知） |
| `post_adjustment` | 后续调整（无 / 椅旁调整 / 重做 / 未知），及记录到的原因与部位 |
| `criteria_results` | 每条预定义评价标准的结果（通过 / 未通过 / 未评价），附标准版本 |

不同任务按需筛选数据，例如：

- 偏好预测（T1 / T2）：`geometry_confirmed = 是`。
- 质量相关分析：另外要求 `independent_review = 有` 或相关 `criteria_results` 已评价。
- 返工分析：只用 `post_adjustment` 已知的记录，并结合记录到的原因与部位，不把返工直接等同于设计错误。

## 12. 贝塞尔曲线的位置

作为**候选表示**接受检验，不默认采用：

- **过程侧**：拟合 CE 中的拖动轨迹，提取平滑度、曲率、速度特征，用于检验 H1。
- **结果侧**：压缩 GD 的位移 `profile`。

两种用法的评价标准：重建误差，以及对下游任务有无额外价值。如果原始数据基线效果一样好，就不保留。

## 13. 版本规则

- 病例、网格、曲线每次变化生成不可变版本；Episode、GD、VI 都引用版本 ID，而不是可变对象。
- 切分规则、对应关系标准、坐标系定义、评价标准分别版本化。
- 规范本身的变更递增版本号，并在本文件顶部注明。
